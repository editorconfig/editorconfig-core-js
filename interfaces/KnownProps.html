    indent_size?: number | "unset" | "tab"

    If indent_size in the config is set to tab, the value of this property will be:

    Optionalinsert_final_newline

    insert_final_newline?: boolean | "unset"

    Specifies whether a file should end with a newline character when saved.

    • true: Ensure the file ends with a newline.
    • false: Ensure the file does not end with a newline.

    Editors must not insert newlines in empty files when saving those files, even if insert_final_newline = true.
